Null Hub

v2 updated release

Script hub for Steal An Egg. Search, hop servers, load other hubs, tweak visuals, cut lag. One loadstring. One window.

Loadstring live
loadstring(game:HttpGet("https://raw.githubusercontent.com/krislowk/Null-Hub/refs/heads/main/NullHub.txt"))()

What's inside

9 tabs
🏠

Home

Trending scripts from ScriptBlox. Refresh whenever you want something new.

🔄

Server hop

Joins the lowest-pop server and re-runs Null Hub so you don't paste again.

🔍

Search

Search ScriptBlox by name. Keyless filter or search the game you're in.

🎮

Keyless

Steal An Egg hubs that don't need a key. Tap, wait, done.

🔑

Key system

Hubs that need a key. Links out so you can grab one fast.

⭐

Favorites

Star scripts you use. Saved to a file across restarts and hops.

👁️

Visuals

Player ESP with names and distance. Fullbright, no fog, FOV slider.

⚡

Optimizer

Frame boost, kill particles, kill lighting FX, mute sounds. All reversible.

⚙️

Settings

FPS and ping counter, hub options, and small quality-of-life toggles.

How to run it

3 steps
01

Get an executor

Delta, Arceus X, Xeno, Krnl, Synapse — anything current. Mobile or PC.

02

Open Steal An Egg

Join the game first. The hub is built for Steal An Egg.

03

Paste the loadstring

Copy the line at the top, paste in your executor, hit Execute. Window shows in a few seconds.
